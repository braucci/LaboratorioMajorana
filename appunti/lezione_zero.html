Atto VI — Disciplina

Salviamo il file
correttamente

Un dettaglio apparentemente banale che fa la differenza tra "funziona" e "non funziona". Windows nasconde le estensioni dei file di default — è la trappola in cui cadono il 90% degli studenti la prima volta.

✅ Modo corretto
  • Apri Blocco Note (Notepad)
  • Incolla il codice copiato da Claude
  • File → Salva con nome…
  • Nome file: index.html
  • Salva come tipo: "Tutti i file (*.*)"
  • Clicca Salva
  • Doppio clic sul file → si apre nel browser
❌ Errori comuni
  • index.html.txt — estensione doppia
  • index.txt — estensione sbagliata
  • index — senza estensione
  • Salvato in Word — formato incompatibile
  • "Documento di testo" anziché "Tutti i file"
⚠️ Punto di attenzione

Windows nasconde di default le estensioni "conosciute" come .txt. Se il tuo file appare semplicemente come index.html ma il browser non lo apre correttamente, è probabile che si chiami in realtà index.html.txt. Soluzione: in Blocco Note, seleziona sempre "Tutti i file (*.*)" prima di salvare.

Atto IX — La prima modifica

Personalizziamo
il codice

La prima vera modifica al codice: cambiare i colori senza rompere nulla. Le variabili CSS in :root { } sono il "pannello di controllo" del tema. Cambiare un solo valore cambia il colore ovunque nel sito — è il principio DRY: Don't Repeat Yourself, uno dei pilastri dell'ingegneria del software.

/* CODICE ORIGINALE */
:root {
  --bg:      #0b0f14;  /* sfondo scuro    */
  --accent:  #00d4ff;  /* ciano brillante */
  --accent2: #ff6b35;  /* arancio         */
  --success: #00e676;  /* verde risultato */
}
/* VERSIONE PERSONALIZZATA */
:root {
  --bg:      #0a0e1a;  /* blu notte    */
  --accent:  #ffd600;  /* giallo neon  */
  --accent2: #e91e63;  /* rosa acceso  */
  --success: #76ff03;  /* lime         */
}
🛠️ Esercizio operativo

Apri index.html con Blocco Note → cerca :root → cambia --accent con il tuo colore preferito → salva → ricarica il browser con F5. Poi carica di nuovo il file su GitHub. In meno di un minuto il sito sarà aggiornato anche online.

Atto X — Il ciclo

Modifica → Testa
→ Carica → Pubblica

Il ciclo che userai per sempre. Quattro passaggi che diventeranno automatici come respirare. È esattamente il workflow reale che si usa in azienda con Git — oggi lo fate a mano, presto lo farete in automatico.

📝
Passo 01
Modifica
Apri index.html con Blocco Note. Fai le modifiche.
🔍
Passo 02
Testa
Doppio clic sul file. Verifica nel browser che funzioni.
☁️
Passo 03
Carica
GitHub → tuo repo. Add file → Upload. Sovrascrivi.
🚀
Passo 04
Pubblica
Commit changes. Aspetta 60 secondi. Sito aggiornato!
🔁 Il workflow reale

Questo ciclo — modifica, testa, carica, pubblica — è identico al workflow professionale che si usa in azienda con Git. La differenza è che in azienda i passaggi 3 e 4 sono automatizzati da comandi come git push. Oggi lo fate a mano. Presto, quando imparerete Git, lo farete con un singolo comando.
