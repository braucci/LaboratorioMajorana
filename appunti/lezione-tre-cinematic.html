Atto I — Il problema

Un programma che esegue
sempre la stessa cosa
è solo una calcolatrice

Finora i nostri script Python hanno fatto una cosa sola: calcolare. Ricevono input, applicano formule, restituiscono output. Sempre uguali. Ma un programma vero deve fare di più: deve decidere, deve ripetere, deve fermarsi quando un'esigenza è soddisfatta. Esattamente come fa un pilota nella checklist pre-volo.

✈️ Analogia aeronautica

Un pilota legge la checklist e decide: se i flap sono al 15%, prosegue; altrimenti li corregge. Ripete il controllo per ogni superficie mobile. Si ferma quando la checklist è completa. Queste tre azioni — decidere, ripetere, fermarsi — sono esattamente le strutture di controllo che impareremo oggi.

Decidere
if / else
"SE la velocità è sotto V_stall, ALLORA avvisa il pilota."
Ripetere
for
"PER ogni punto del profilo NACA, calcola la coordinata y."
Fermarsi
while
"FINCHÉ la portanza non bilancia il peso, aumenta l'angolo d'attacco."
Atto II — Regola d'oro

In Python, gli spazi
contano davvero

In altri linguaggi i blocchi di codice si delimitano con parentesi graffe. In Python si delimitano con l'indentazione: gli spazi all'inizio della riga. Tutto ciò che è "più dentro" rispetto a un if o un for appartiene a quel blocco. Questa non è una scelta estetica: è la sintassi.

❌ Indentazione sbagliata
quota = 11000
if quota > 10000:
print("Stratosfera!")  ← errore
densita = 0.36
✅ Indentazione corretta
quota = 11000
if quota > 10000:
    print("Stratosfera!")
    densita = 0.36
⚠️ IndentationError

È l'errore più frequente dei principianti. Python è severissimo: 4 spazi (o 1 tab, ma sempre uno solo) di rientro per ogni livello. Se mescoli tab e spazi, il programma si rifiuta di partire. Visual Studio Code e Thonny inseriscono 4 spazi automaticamente quando premi Tab.

Atto III — Decidere

if / elif / else
— la logica del pilota

L'istruzione if esegue un blocco di codice solo se una condizione è vera. Aggiungendo elif (else-if) e else si costruisce un albero di decisione che copre tutti i casi possibili. È così che ogni avionica moderna decide cosa mostrare al pilota.

# Velocità di stallo per un aliante (in m/s)
V_stall = 14.5
V_attuale = float(input("Velocità attuale [m/s]: "))

if V_attuale < V_stall:
    print("⚠️ STALLO! Aumenta velocità immediatamente.")
elif V_attuale < 1.3 * V_stall:
    print("⚡ Attenzione: prossimo allo stallo (V < 1.3·V_stall)")
elif V_attuale < 2.0 * V_stall:
    print("✓ Volo livellato sicuro")
else:
    print("🚀 Crociera")

💡 Confronto fondamentale

Un singolo "=" serve per assegnare un valore: x = 5. Un doppio "==" serve per confrontare due valori: if x == 5:. È l'errore di sintassi più subdolo: il programma non si rifiuta di partire, ma fa qualcosa di diverso da quello che pensavi.

Atto IV — Dal pensiero al codice

Pensa in italiano,
scrivi in Python

Prima di scrivere il codice, scrivi lo pseudocodice: la logica in italiano. È il passaggio mentale che separa chi programma bene da chi programma a caso. La traduzione in Python diventa quasi meccanica.

Pseudocodice (italiano)
# Calcolo numero di Mach
LEGGI velocità v (m/s)
LEGGI temperatura T (K)

CALCOLA velocità del suono:
  a = √(1.4 · 287 · T)

CALCOLA Mach:
  M = v / a

SE M < 0.8 ALLORA
  STAMPA "Regime subsonico"
ALTRIMENTI SE M < 1.2 ALLORA
  STAMPA "Regime transonico"
ALTRIMENTI
  STAMPA "Regime supersonico"
Python
# Calcolo numero di Mach
v = float(input("v [m/s]: "))
T = float(input("T [K]: "))

# velocità del suono
a = (1.4 * 287 * T) ** 0.5

# Mach
M = v / a

if M < 0.8:
    print("Subsonico")
elif M < 1.2:
    print("Transonico")
else:
    print("Supersonico")
🎯 La regola dei tre passi

Per ogni problema: 1) scrivi cosa vuoi fare in italiano semplice; 2) traducilo in pseudocodice strutturato; 3) traducilo in Python. Saltando il passo 1 e il passo 2 si finisce a scrivere codice "a tentativi". Funziona forse il 30% delle volte.

Atto V — Ripetere

for — quando sai
quante volte ripetere

Il ciclo for esegue lo stesso blocco di istruzioni per ogni elemento di una sequenza. Per disegnare un profilo NACA con 21 punti, non scriviamo 21 righe di calcolo: scriviamo una sola istruzione che si ripete 21 volte.

# Genera 21 punti del profilo NACA 0012 (simmetrico, t = 0.12)
t = 0.12

for i in range(21):
    x = i / 20                       # x va da 0 a 1
    y = (t / 0.20) * (
        0.2969 * x**0.5
        - 0.1260 * x
        - 0.3516 * x**2
        + 0.2843 * x**3
        - 0.1015 * x**4
    )
    print(f"x = {x:.3f}   y = {y:.5f}")
🔄 Cosa fa range()

range(21) genera la sequenza 0, 1, 2, … 20 — esattamente 21 numeri. range(5, 10) genera 5, 6, 7, 8, 9 (l'estremo finale è escluso). range(0, 10, 2) genera 0, 2, 4, 6, 8 — terzo argomento è il passo.

La variabile i assume uno dopo l'altro tutti questi valori. È la nostra "rotellina contagiri".

✨ f-string

La f"..." è una "formatted string": permette di inserire variabili dentro un testo. {x:.3f} stampa x con 3 decimali. Fondamentale per output leggibili in ambito tecnico.

Atto VI — Convergere

while — finché
la condizione regge

Il ciclo while ripete un blocco fintantoché una condizione è vera. Lo usiamo quando non sappiamo a priori quante iterazioni serviranno. Esempio classico: calcolo iterativo della velocità di stallo che converge per approssimazioni successive.

# Trova V_stall tale che L = W per un aliante
W     = 3500      # peso [N]
rho   = 1.225     # densità ISA SL [kg/m³]
S     = 11.5      # superficie alare [m²]
CL_max = 1.4      # CL massimo

V     = 10.0     # tentativo iniziale [m/s]
passo = 0.1      # incremento [m/s]

while 0.5 * rho * V**2 * S * CL_max < W:
    V += passo

print(f"V_stall ≈ {V:.2f} m/s = {V*3.6:.1f} km/h")
🚨 Loop infinito

Il pericolo principale del while: se la condizione non diventa mai falsa, il programma non si ferma più. Devi sempre assicurarti che qualcosa dentro il ciclo modifichi le variabili coinvolte nella condizione. Nell'esempio sopra: V += passo incrementa V ad ogni giro — è ciò che garantisce la terminazione.

Se il tuo programma non risponde più: premi CTRL+C nel terminale per interromperlo.

🔧 Scorciatoie operative

V += 0.1 equivale a V = V + 0.1. Esistono anche -=, *=, /=. Sono le scorciatoie più usate nei cicli iterativi.

Atto VII — Controllare il flusso

break e continue
— le uscite di emergenza

Due parole chiave per controllare cosa succede dentro un ciclo: break esce immediatamente dal ciclo, continue salta direttamente alla prossima iterazione. Sono le uscite di emergenza dei loop.

# Stesso calcolo di V_stall, ma con criterio di precisione
V = 10.0
tolleranza = 0.001

while True:                       # loop apparentemente infinito
    L = 0.5 * 1.225 * V**2 * 11.5 * 1.4
    if abs(L - 3500) < tolleranza:
        break                       # esce dal while
    V += 0.001

print(f"V_stall = {V:.4f} m/s")
# Calcolo Mach per varie quote, scartando quote impossibili
v = 250                         # velocità [m/s]
quote = [0, 3000, -100, 9000, 15000]

for h in quote:
    if h < 0:
        continue                   # salta quote negative
    T = 288.15 - 0.0065 * h     # ISA
    a = (1.4 * 287 * T) ** 0.5
    M = v / a
    print(f"h = {h} m   M = {M:.3f}")
Atto VIII — Esempio completo

Costruiamo una
tabella ISA

Combiniamo le tre strutture in un programma vero: una tabella di atmosfera standard ISA dal suolo a 20 km, con avviso quando si entra in stratosfera. Tre concetti, un'unica applicazione utile per ogni studente di aerodinamica.

# ─── Parametri atmosfera standard ISA ──────────────
T0    = 288.15      # temperatura al suolo [K]
P0    = 101325      # pressione al suolo [Pa]
rho0  = 1.225       # densità al suolo [kg/m³]
L     = 0.0065      # gradiente termico troposfera [K/m]
g     = 9.80665     # gravità [m/s²]
R     = 287.05      # costante aria [J/(kg·K)]
h_tropopausa = 11000  # [m]

print(f"{'h [m]':>8} {'T [K]':>8} {'p [Pa]':>10} {'ρ [kg/m³]':>12}")
print("─" * 42)

for h in range(0, 20001, 1000):     # 0, 1000, …, 20000 m

    if h <= h_tropopausa:
        # Troposfera: temperatura cala linearmente
        T = T0 - L * h
        P = P0 * (T/T0)**(g/(L*R))
    else:
        # Stratosfera: temperatura costante (isotermica)
        T_trop = T0 - L * h_tropopausa
        P_trop = P0 * (T_trop/T0)**(g/(L*R))
        T = T_trop
        import math
        P = P_trop * math.exp(-g*(h-h_tropopausa)/(R*T))

    rho = P / (R * T)
    print(f"{h:>8} {T:>8.2f} {P:>10.0f} {rho:>12.4f}")
🎓 Cosa abbiamo usato

for per scorrere le quote da 0 a 20 km · if/else per distinguere troposfera e stratosfera · f-string per formattare colonne allineate. Un esempio pedagogicamente perfetto: in 25 righe abbiamo riprodotto la prima pagina di un manuale di aerodinamica.

⚡ Perché funziona

Python e JavaScript condividono il 90% della logica di base: if, for, while esistono in entrambi con sintassi quasi identica. Le differenze sono nei dettagli: parentesi graffe invece dell'indentazione, Math.sqrt(x) invece di x**0.5, let invece dell'assegnazione diretta. L'IA queste differenze le conosce a memoria: la traduzione è meccanica.
