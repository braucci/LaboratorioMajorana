§ 01 · Il problema

Un programma che esegue
sempre la stessa cosa
è solo una calcolatrice.

Finora i nostri script Python hanno fatto una cosa sola: calcolare. Ricevono input, applicano formule, restituiscono output. Sempre uguali. Ma un programma vero deve fare di più: deve decidere, deve ripetere, deve fermarsi quando un'esigenza è soddisfatta.

✈️ Analogia aeronautica
Un pilota legge la checklist e decide: se i flap sono al 15%, prosegue; altrimenti li corregge. Ripete il controllo per ogni superficie mobile. Si ferma quando la checklist è completa. Queste tre azioni — decidere, ripetere, fermarsi — sono esattamente le strutture di controllo che impareremo oggi.
Azione · 01
Decidere (if/else)
"SE la velocità è sotto V_stall, ALLORA avvisa il pilota."
Azione · 02
Ripetere (for)
"PER ogni punto del profilo NACA, calcola la coordinata y."
Azione · 03
Fermarsi (while)
"FINCHÉ la portanza non bilancia il peso, aumenta l'angolo d'attacco."
§ 02 · Regola d'oro

In Python, gli spazi
contano davvero.

In altri linguaggi i blocchi di codice si delimitano con parentesi graffe. In Python si delimitano con l'indentazione: gli spazi all'inizio della riga. Tutto ciò che è "più dentro" rispetto a un if o un for appartiene a quel blocco. Questa non è una scelta estetica: è la sintassi.

✗ Indentazione sbagliata
IndentationError
quota = 11000
if quota > 10000:
print("Stratosfera!")  # ← errore
densita = 0.36
✓ Indentazione corretta
Sintassi valida
quota = 11000
if quota > 10000:
    print("Stratosfera!")
    densita = 0.36
⚠️ Errore critico per i principianti
Python è severissimo: 4 spazi (o 1 tab, ma sempre uno solo) di rientro per ogni livello. Se mescoli tab e spazi, il programma si rifiuta di partire. Gli editor di testo come VS Code e Thonny inseriscono 4 spazi automaticamente quando premi Tab.
§ 03 · Decidere

if / elif / else
— la logica del pilota.

L'istruzione if esegue un blocco di codice solo se una condizione è vera. Aggiungendo elif (else-if) e else si costruisce un albero di decisione che copre tutti i casi possibili. È così che ogni avionica moderna decide cosa mostrare sullo schermo.

velocita_stallo.py
1# Velocità di stallo per un aliante (in m/s) 2V_stall = 14.5 3V_attuale = float(input("Velocità attuale [m/s]: ")) 4 5if V_attuale < V_stall: 6 print("⚠️ STALLO! Aumenta velocità immediatamente.") 7elif V_attuale < 1.3 * V_stall: 8 print("⚡ Attenzione: prossimo allo stallo (V < 1.3·Vs)") 9elif V_attuale < 2.0 * V_stall: 10 print("✓ Volo livellato sicuro") 11else: 12 print("🚀 Crociera")
OperatoreSignificatoEsempio
==Uguale a (confronto)x == 5
!=Diverso dax != 0
< / >Minore / MaggioreM < 1.0
<= / >=Minore o uguale / Magg. o ugualeRe >= 1e6
and / or / notOperatori logici (E, O, Negazione)V > 100 and h < 5000
💡 Un confronto fondamentale
Un singolo "=" serve per assegnare un valore: x = 5.
Un doppio "==" serve per confrontare due valori: if x == 5:.
Confondere i due è l'errore di logica più subdolo: il programma esegue un'operazione completamente diversa da quella che avevi in mente.
§ 04 · Dal pensiero al codice

Pensa in italiano,
scrivi in Python.

Prima di scrivere il codice, scrivi lo pseudocodice: la logica in italiano. È il passaggio mentale che separa chi programma bene da chi procede a tentativi. La traduzione in Python diventa quasi meccanica.

Pseudocodice (italiano)

# Calcolo numero di Mach
LEGGI velocità v (m/s)
LEGGI temperatura T (K)

CALCOLA velocità del suono:
  a = √(1.4 · 287 · T)

CALCOLA Mach:
  M = v / a

SE M < 0.8 ALLORA
  STAMPA "Regime subsonico"
ALTRIMENTI SE M < 1.2 ALLORA
  STAMPA "Regime transonico"
ALTRIMENTI
  STAMPA "Regime supersonico"

Python

# Calcolo numero di Mach
v = float(input("v [m/s]: "))
T = float(input("T [K]: "))

# velocità del suono
a = (1.4 * 287 * T) ** 0.5

# Mach
M = v / a

if M < 0.8:
    print("Subsonico")
elif M < 1.2:
    print("Transonico")
else:
    print("Supersonico")
🎯 La regola dei tre passi
Per ogni problema: 1) scrivi cosa vuoi fare in italiano semplice; 2) traducilo in pseudocodice strutturato; 3) traducilo in Python. Saltando il passo 1 e il passo 2 si finisce a scrivere codice per "trial & error".
§ 05 · Ripetere

for — quando sai
quante volte ripetere.

Il ciclo for esegue lo stesso blocco di istruzioni per ogni elemento di una sequenza. Per disegnare un profilo NACA con 21 punti, non scriviamo 21 righe di calcolo: scriviamo una sola istruzione che si ripete 21 volte variando la x.

naca_0012.py
1# Genera 21 punti del profilo NACA 0012 (simmetrico, t = 0.12) 2t = 0.12 3 4for i in range(21): 5 x = i / 20 # x va da 0 a 1 6 y = (t / 0.20) * ( 7 0.2969 * x**0.5 8 - 0.1260 * x 9 - 0.3516 * x**2 10 + 0.2843 * x**3 11 - 0.1015 * x**4 12 ) 13 print(f"x = {x:.3f} y = {y:.5f}")
🔄 Cosa fa range()
range(21) genera la sequenza 0, 1, 2, … 20 — esattamente 21 numeri. range(5, 10) genera 5, 6, 7, 8, 9 (l'estremo finale è escluso). La variabile i assume uno dopo l'altro tutti questi valori. È la nostra "rotellina contagiri".
✨ f-string
La f"..." è una "formatted string": permette di inserire variabili direttamente dentro un testo racchiudendole in parentesi graffe. {x:.3f} stampa x con 3 decimali. Fondamentale per output leggibili e precisi in ambito tecnico.
§ 06 · Convergere

while — finché
la condizione regge.

Il ciclo while ripete un blocco fintantoché una condizione è vera. Lo usiamo quando non sappiamo a priori quante iterazioni serviranno. Esempio classico: un calcolo iterativo (come trovare la velocità di stallo) che converge per approssimazioni successive.

convergenza_stallo.py
1# Trova V_stall tale che la portanza (L) bilanci il peso (W) 2W = 3500 # peso [N] 3rho = 1.225 # densità ISA SL [kg/m³] 4S = 11.5 # superficie alare [m²] 5CL_max = 1.4 # coefficiente di portanza massimo 6 7V = 10.0 # tentativo iniziale [m/s] 8passo = 0.1 # incremento ad ogni iterazione [m/s] 9 10while 0.5 * rho * V**2 * S * CL_max < W: 11 V += passo 12 13print(f"V_stall ≈ {V:.2f} m/s = {V*3.6:.1f} km/h")
🚨 Loop infinito
Il pericolo principale del while: se la condizione non diventa mai falsa, il programma non si ferma più. Devi sempre assicurarti che qualcosa dentro il ciclo modifichi le variabili coinvolte nella condizione. Sopra, V += passo incrementa V, garantendo la terminazione. Se il programma si incanta, premi CTRL+C nel terminale per interromperlo.
§ 07 · Controllare il flusso

break e continue
— le uscite di emergenza.

Due parole chiave per controllare cosa succede dentro un ciclo: break esce immediatamente dal loop spezzandolo, continue salta direttamente alla prossima iterazione ignorando il resto del blocco.

break_continue.py
1# Calcolo Mach per varie quote, scartando le quote negative 2v = 250 # velocità fissa [m/s] 3quote = [0, 3000, -100, 9000, 15000] 4 5for h in quote: 6 if h < 0: 7 continue # salta alla prossima iterazione (ignora -100) 8 9 if h > 11000: 10 print("Entrato in stratosfera. Calcolo interrotto.") 11 break # esce definitivamente dal ciclo for 12 13 T = 288.15 - 0.0065 * h # temp ISA troposferica 14 a = (1.4 * 287 * T) ** 0.5 15 M = v / a 16 print(f"h = {h:4d} m M = {M:.3f}")
§ 08 · Esempio pratico

Costruiamo una
Tabella ISA completa.

Combiniamo le tre strutture in un programma vero: una tabella di atmosfera standard ISA dal suolo a 20 km, discriminando tra Troposfera (T cala) e Stratosfera (T costante). Tre concetti fusi per un'applicazione utilissima in Aerodinamica.

tabella_isa.py
1# Parametri base ISA 2T0 = 288.15; P0 = 101325; R = 287.05; g = 9.80665; L = 0.0065 3h_trop = 11000 4 5print(f"{'h [m]':>8} {'T [K]':>8} {'p [Pa]':>10} {'ρ [kg/m³]':>12}") 6print("─" * 42) 7 8for h in range(0, 20001, 1000): # Da 0 a 20km, a passi di 1km 9 10 if h <= h_trop: 11 # --- TROPOSFERA --- 12 T = T0 - L * h 13 P = P0 * (T/T0)**(g/(L*R)) 14 else: 15 # --- STRATOSFERA --- 16 T_trop = T0 - L * h_trop 17 P_trop = P0 * (T_trop/T0)**(g/(L*R)) 18 T = T_trop 19 import math 20 P = P_trop * math.exp(-g*(h-h_trop)/(R*T)) 21 22 rho = P / (R * T) 23 print(f"{h:>8} {T:>8.2f} {P:>10.0f} {rho:>12.4f}")
🎓 Cosa abbiamo usato
for per scorrere le quote da 0 a 20 km · if/else per distinguere fisicamente troposfera e stratosfera · f-string per formattare colonne allineate. Un esempio pedagogicamente perfetto: in 20 righe abbiamo riprodotto la prima pagina di un manuale di aerodinamica.
§ 09 · Dal terminale al browser

Da Python
al web, in un prompt.

Lo script Python che avete appena scritto gira solo nel terminale. Per condividerlo, dovete trasformarlo in una Web App (HTML+JS) interattiva. Non dovete riscriverlo da zero: chiedete all'IA di fare il porting, garantendo che la logica di controllo resti immutata.

✓ Prompt di Conversione in Web App
Il passaggio magico
Ho scritto questo script Python che calcola [descrivi cosa fa]. Voglio trasformarlo in una web app: un singolo file HTML che fa esattamente la stessa cosa, ma con interfaccia grafica nel browser.

REQUISITI:
1. Un solo file 'index.html' — niente librerie esterne.
2. Riproduci ESATTAMENTE la stessa logica e formule del mio Python.
3. Gli input del Python (input()) diventano campi modificabili.
4. Gli output (print()) diventano testo o tabelle a schermo.
5. Tema scuro stile aeronautico: sfondo #0b0f14, accent #00d4ff.
6. Se usi 'math', traduci in Math.* di JavaScript.

ECCO IL MIO CODICE PYTHON: [INCOLLA SCRIPT QUI]
⚡ Perché funziona così bene
Python e JavaScript condividono la stessa logica di base: if, for, while esistono in entrambi con sintassi quasi identica. Cambiano i dettagli (parentesi graffe invece di indentazione), che l'IA sa tradurre meccanicamente. Questo è l'approccio ingegneristico moderno: si prototipa in Python, si converte il prodotto finito nel linguaggio di destinazione.
